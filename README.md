# Clauser AI

Clauser AI is a **multi-agent** contract analyzer platform that automates legal and business contract review through **workflow orchestration and Retrieval Augmented Generation**. The system identifies contractual risks, validates compliance requirements, enforces organizational playbooks, generates negotiation recommendations, and produces executive summaries from uploaded agreements.

Powered by **LangGraph-based agent orchestration, RAG pipelines, vector search, and structured AI workflows, Clauser AI showcases how specialized AI agents can collaborate to solve complex enterprise review processes that traditionally require significant manual effort.**

Live Demo: https://clauser-ai-by-kanisk.netlify.app/

# Problem Statement

Contract review remains one of the most time-consuming activities in legal and business operations.

Organizations regularly process:

* Vendor agreements
* Master Service Agreements (MSAs)
* Employment contracts
* Terms of Service
* Licensing agreements
* Procurement contracts

Traditional review workflows suffer from several challenges:

### Manual Review Bottlenecks

Legal teams must manually inspect hundreds of clauses for liability exposure, payment risks, confidentiality concerns, and regulatory compliance.

### Inconsistent Risk Identification

Different reviewers often identify different issues, leading to inconsistent risk assessments across contracts.

### Compliance Gaps

Organizations operating under privacy and regulatory frameworks must ensure contracts satisfy legal obligations before execution.

### Playbook Enforcement Challenges

Many organizations maintain internal legal playbooks, but verifying every contract against those standards is difficult and expensive.

### Negotiation Delays

Risk identification alone is insufficient. Teams also need alternative clause language and negotiation recommendations before engaging counterparties.

These challenges increase review costs, slow contract cycles, and expose organizations to avoidable legal and financial risks.

---

# Solution

Clauser AI introduces a multi-agent legal review pipeline where each specialized agent focuses on a distinct stage of contract analysis.

Instead of relying on a single prompt and a single response, the platform orchestrates multiple agents that collaboratively analyze contracts from different perspectives.

Core capabilities include:

* Contract risk identification
* Regulatory compliance assessment
* Company playbook validation
* Negotiation recommendation generation
* Executive summary creation
* Contract health scoring
* Knowledge-enhanced analysis through RAG

The architecture enables more structured and explainable outputs compared to conventional single-prompt legal assistants.

# Technical Deep Dive

## Workflow Orchestration with LangGraph

Rather than chaining prompts sequentially, the platform uses a state-driven graph architecture.

Advantages:

* Agent isolation
* Structured state management
* Extensibility
* Clear execution paths

This mirrors production-grade AI systems used in enterprise agentic applications.

---

## Retrieval-Augmented Legal Analysis

Policy documents are:

1. Parsed
2. Chunked
3. Embedded
4. Indexed
5. Retrieved during analysis

This enables contract reviews to incorporate organization-specific legal standards rather than relying solely on foundation model knowledge.

---

## Structured AI Outputs

Agents are instructed to return JSON-only responses.

Advantages:

* Deterministic parsing
* Reliable UI rendering
* Reduced hallucination risk
* Easier downstream automation

Used extensively across:

* Risk analysis
* Compliance analysis
* Negotiation generation
* Playbook validation

---

## Evaluation Pipeline

A dedicated evaluation workflow assesses output quality using an independent LLM-based judge.

Benefit:

* Enables automated validation of generated legal insights.

# Workflow

1. Upload a contract.
2. Optionally upload internal playbook documents.
3. Contract text is extracted.
4. Playbooks are indexed into the vector database.
5. Planner agent determines analysis strategy.
6. Risk agent identifies contractual issues.
7. Playbook agent validates organizational compliance.
8. Compliance agent checks regulatory obligations.
9. Negotiation agent generates alternative language.
10. Executive summary agent creates leadership-ready insights.
11. Judge agent calculates contract health score.
12. Results are displayed through an interactive dashboard.

# Challenges & Solutions

## Challenge: Reliable Multi-Agent Coordination

Problem:

Multiple AI agents must share context without losing consistency.

Solution:

Implemented a centralized LangGraph state architecture enabling deterministic information flow between agents.

---

## Challenge: Organization-Specific Legal Standards

Problem:

Generic LLMs cannot understand company-specific policies.

Solution:

Implemented RAG-based retrieval using ChromaDB and uploaded playbooks.

---

## Challenge: Structured AI Outputs

Problem:

LLMs often return inconsistent formatting.

Solution:

Enforced strict JSON-based schemas across all agents for predictable parsing and rendering.

# Installation

```bash
git clone https://github.com/yourusername/clauser-ai.git

cd clauser-ai

pip install -r requirements.txt
```

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key
```

Run Backend:

```bash
uvicorn main:app --reload
```

Open frontend in browser.

# Project Highlights

Clauser AI demonstrates the design and implementation of an enterprise-style AI system rather than a simple chatbot.

The project combines agent orchestration, retrieval-augmented generation, workflow management, vector search, structured output generation, legal compliance analysis, and evaluation pipelines into a single production-oriented application.

The architecture emphasizes modularity, explainability, extensibility, and operational usefulness, making it significantly closer to real-world AI products than conventional CRUD applications or single-prompt AI demos.
